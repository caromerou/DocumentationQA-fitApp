# 🚀 Desarrollo de Aplicación Web para la Promoción de Actividad Física — FIT APP

Repositorio oficial del proyecto de grado enfocado en el desarrollo de un prototipo de aplicación web para la divulgación y consulta de un protocolo de promoción de la actividad física dirigido a estudiantes de educación superior (Universidad de Santander).

---

## 📋 Descripción del Proyecto
Este proyecto surge como respuesta a la necesidad de ofrecer un medio tecnológico digital que facilite el acceso de los estudiantes universitarios a las orientaciones de actividad física recopiladas por el programa de Fisioterapia. El alcance se limita al diseño, construcción y evaluación de la solución tecnológica (arquitectura de tres capas, interfaz web responsiva y cumplimiento de pautas de accesibilidad WCAG 2.1), sin modificar el contenido base del protocolo ni evaluar directamente cambios en los hábitos de actividad física.

## 🗂️ Estructura del Repositorio y Contenido de Carpetas

A continuación se detalla el contenido de los archivos y carpetas organizados en este repositorio:

| Carpeta / Directorio | Descripción del Contenido |
| :--- | :--- |
| **`Automation (propuesta)`** ⚠️ | Carpeta que contiene archivos preliminares de automatización. **Nota importante:** Actualmente es solo una propuesta conceptual y **no es funcional** dentro de la fase actual del prototipo. |
| **`Historias_Usuario`** | Contiene la especificación detallada de las Historias de Usuario bajo el marco Scrum (como la *HU-01: Registrar una cuenta* y la *HU-02: Activar la cuenta después del registro*), incluyendo criterios de aceptación, campos de entrada/salida y control de cambios. |
| **`Manual_Usuario`** | Documentación de la guía de usuario final que explica paso a paso la navegación y consulta de los módulos de actividad física dentro de la aplicación. |
| **`Plan_Pruebas`** | Matriz y plan completo de pruebas de software (*Plan_de_Pruebas_FIT_APP_Completo_v2.xlsx*) para la verificación de requerimientos funcionales, flujos de navegación (como el Home/Landing Page y autenticación) y control de calidad. |
| **`Plantillas_Evidencia&Bugs`** | Formatos y plantillas estandarizadas para el registro de evidencias de ejecución de pruebas y el reporte de defectos/bugs detectados durante la evaluación del prototipo. |

## 🛠️ Marco Tecnológico y Metodología
* **Arquitectura:** Arquitectura de tres capas (Presentación, Lógica/Negocio y Acceso a Datos).
* **Metodología de Desarrollo:** Enfoque ágil basado en Scrum (Product Backlog y Sprints)[cite: 8].
* **Evaluación de Calidad:** Adaptación de la escala MARS y criterios del estándar ISO/IEC 25010:2023 (adecuación funcional y mantenibilidad).
